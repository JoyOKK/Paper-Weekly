ARDY：混合表征上的自回归扩散，做交互式人体动作生成

Autoregressive Diffusion with Hybrid Representation for Interactive Human Motion Generation

SIGGRAPH / ACM TOG 2026 · NVIDIA + ETH Zürich
Zhao, Petrovich, Zhang, Wang, Tang, Rempe
Project · arXiv:2607.08741 · GitHub

阅读提纲

今天看什么

  • 挑战：离线可控但慢，在线实时但控不住长程语义与目标。
  • Idea：显式 root + 隐式 body，两阶段自回归扩散。
  • 方法：FSQ tokenizer、可变历史、窗口外目标、root overwrite。
  • 结果：4-step ≈ 33 ms；HumanML3D 上优于 DiP，控制误差接近离线优化方法但不依赖 RL。
问题

交互场景要的是「实时 + 可控」

动画、游戏、仿真、人形机器人都需要在运行时生成逼真 3D 人体动作，并且能立刻响应文本和空间指令。

离线生成

扩散 / 掩码模型能跟复杂文本，也能卡关键帧、关节位置。整段并行去噪，延迟高，改一句 prompt 就要重跑全序列。

在线生成

自回归很快，角色能边走边反应。但多数工作只能控文本或只能控运动学；历史一短，复杂语义和 10 秒后的路点就做不到。

挑战

现有方法为什么接不住

控制与速度互斥

Kimodo / MaskControl 控制强，但不是实时；A-MDM、CAMDM 实时，却几乎没有复杂文本。

上下文太短

DiP、DartControl 历史只有零点几到 2 秒。「先走再弯腰捡东西再走」这种非周期语义会漏做或重复做。

窗口外目标靠补丁

长程路点、10 秒后到某点，先前工作用测试时优化或再训一个 RL 策略，交互里太贵。

本文切入点

原生同时吃在线文本 + 稀疏长程运动学约束，不额外挂优化器 / RL，还要压到交互延迟。

核心 Idea

把「好控的轨迹」和「好学的身体」拆开

Hybrid 表征：全局显式 root（位置 + heading）保留可覆盖、可解释的轨迹；body 压进 tokenizer latent，让少步扩散学得动。

生成时用交错两阶段 Transformer：先出干净 root，再条件出 body。约束写成 masked 显式动作——当前窗口内的 root 直接 overwrite，窗口外的目标作为额外 token 喂进去。

贡献

论文三条贡献

  • Hybrid 表征：latent body + explicit root，兼顾生成效率与精确轨迹控制，避免局部速度积分漂移。
  • 两阶段自回归扩散：可变历史（最长 8s）+ 最长 10s 未来约束；支持 root 路径 / 路点、全身关键帧、稀疏关节位置与旋转。
  • 大规模验证：Bones Rigplay（约 700h，150+ 演员）做消融；HumanML3D 对比离线 MaskControl 与在线 DiP。交互 demo 支持动态文本、路径跟随、键鼠 locomotion。

方法 · 总览

两段式流水线

1. Body tokenizer
把高维身体特征压成 FSQ latent；与 patch 化的显式 root 拼成 hybrid token。
→
2. 两阶段去噪器
条件：文本、可变历史、masked 目标。先预测 root，再预测 body。
→
3. 解码回放
tokenizer decoder 还原身体；滑动窗口自回归，延迟感知重规划。
方法 · 表征

为什么一定要拆 root / body

x = (m_root, x_body)    m_root = (p, cos ψ, sin ψ) ∈ R⁵
  • 全局 root 可直接 overwrite，空间约束多半定义在场景坐标里，不会被局部速度积分放大误差。
  • body 用 tokenizer 压到紧凑 latent，少步扩散（4–10 step）才学得动；纯显式表征在同样设定下 FID / 路点误差明显变差。
  • 每个 token 对应 P=4 帧。解码器把全局 root 转成本地速度 (ψ̇, ṗx, ṗz, py)，滑步从 0.303 降到 0.264 m/s。
方法 · Tokenizer

因果 AE + FSQ，不对称条件解码

  • Encoder / decoder 各 8 层因果 Transformer，latent 512。输入按 P 帧 patch。
  • 试过 vanilla AE / VAE / FSQ：效果接近，但 AE 在 40 帧 horizon 上会训崩；FSQ（64 级 × 128 维）更稳，作为默认。
  • 重建损失 + 脚接触滑步损失（权重 0.01）。训练 4M step，单卡 A100。
  • Patch=1 后期不稳；Patch=8 FID 略好但细节和约束精度掉。默认 Patch=4 是质量和可控的折中。
方法 · 问题形式

短窗口生成，但条件可以看很远

x1:C = F(s, x(−H+1):0, g1:(C+F))
  • 每次只生成当前窗口 C 个 token（默认 G=40 帧 = 2s @20fps），才能边播边改条件。
  • H 从 0 到最长 8s 可变。长历史用来记住「捡东西有没有做过」，避免短窗口模型漏动作 / 重复动作。
  • g 可以落在窗口外：10 秒后到某点，会从第一步就决定朝哪跑。以前这事要另训 RL，这里是原生条件。
方法 · 约束

约束 = masked 显式动作

  • 任意稀疏：只在被约束的特征 / 时刻填值，其余为 0，另跟一份 binary mask v。
  • Root overwrite：把 noisy root 中被约束的维直接换成目标。轨迹跟得死，是全局移动的骨架。
  • Body：显式身体目标 + 全 mask 拼进输入 token，模型知道哪些关节被钉住。
  • 窗口外目标没有 noisy token，直接作为额外 token 送进 Transformer，长度和稀疏度随用户变。
方法 · 去噪器

交错两阶段，而不是一次出 root+body

  • 每一步：Root Transformer 先预测干净全局 root；detach 后再给 Body Transformer 预测 latent body。
  • 拼回 hybrid，加噪进入下一步。两支路在去噪循环里持续互相看见。
  • 假设：先有干净轨迹，再生成身体，比两者一起预测更容易同时满足文本和约束。

消融（Table 2）

单阶段在路点误差上从 0.024 m 升到 0.164 m；纯显式表征路点 0.203 m、R-prec 掉到 53.9。两阶段 + hybrid 是控制精度的主因。

方法 · 训练

损失与数据怎么喂约束

L = L_hybrid + L_dec + L_goal + L_consist
  • hybrid / 解码 body 用 smooth L1；L_goal 只罚被 mask 住的约束维；L_consist 对齐预测关节位置与 FK(旋转)。
  • 文本用 LLM2Vec（Llama-3-8B-Instruct 上训的 embedding）。Denoiser 约 156M，不用 dropout（会丢掉 root 条件）。
  • 约束从 GT 采样：2D root 关键帧 / 轨迹、全身稀疏或成块关键帧、末端执行器、脚接触。文本与约束各 10% dropout 做 CFG。
  • 默认 10-step DDPM；4-step 已够大多数交互。四卡 A100，1M step。
系统

延迟感知重规划，才能真交互

  • 滚动时把上一窗当作历史；root 先平移到原点再预测，再加回场景坐标。
  • 新文本或新目标到来，或 buffer 快播完，就触发 replan。
  • 已生成的 B 帧一边回放、一边当历史送给异步生成线程，把推理延迟藏起来。
  • RTX 4090：4-step 33 ms、不需要 buffer；10-step 63 ms、用 1 帧 buffer。生成窗 40 帧 / 2s。
  • 键鼠：鼠标路点插值平滑成轨迹；键盘速度积分出 root 轨迹再喂给模型。

实验 · 对比

HumanML3D：离线与在线两边都打

vs MaskControl（离线）

无优化：ARDY 关节误差 4.15 cm vs 46.18 cm，延迟 0.15s vs 0.46s。加优化后两边都能到亚厘米，但 MaskControl 要 68s，ARDY 约 9s。

vs DiP（在线）

窗口内目标：误差 2.48 vs 9.20 cm。窗口外目标：2.92 vs 17.64 cm，FID 0.100 vs 1.453。人评更偏 ARDY（质量 65.8% / 语义 / 目标精度）。

公开集实验用 vanilla AE tokenizer，隔离私有数据影响。评测器仍是原 HumanML3D 预处理上训的，作者认为自己略吃亏。

讨论

局限

  • 历史是把过去帧全喂进去，超长任务会不经济，结构化记忆还没做。
  • 仍是多步扩散，可以再叠 shortcut / consistency 往下压延迟。
  • 纯运动学，没有物理；滑步、抖动还会出现。作者把「运动学生成 + 动力学」统一当成下一步。
带走

阅读收获

表征拆分

要精确覆盖的量（全局 root）显式留着；要靠生成模型学的高维身体压进 latent。这比「全显式」或「全隐式」更适合实时可控。

控制别后挂

从 GT 采样约束、训练时就条件化，比测试时优化 / 再训 RL 更适合交互。窗口外目标当成 token，比加长生成窗便宜。

短生成、长条件

生成窗保持 2s 保证跟手；历史和未来目标可以到 8–10s。质量和反应速度用 horizon 做对换（40 vs 8）。

对工作的启发

做实时动作系统时，优先问：哪些自由度必须 overwrite，哪些可以进 tokenizer；长程目标能不能变成条件 token，而不是另挂控制器。
